Media Hub for AI agents

Media Hub is both a media library and a callable task service. Claude, Codex, and other MCP-compatible agents use the same agent-tools connection.

  1. Connect the agent to the installed agent-tools MCP bridge.
  2. Call discover_tools to get current machine IDs, availability, and input schemas.
  3. Call call_tool with the exact machine, tool name, and inputs.

Download a YouTube transcript

discover_tools({"query":"YouTube"})

call_tool({
  "nodeId": "NODE_ID_FROM_DISCOVERY",
  "name": "media-hub.transcript",
  "input": {"url":"https://www.youtube.com/watch?v=VIDEO_ID", "language":"en"}
})

The result contains transcript text and paths to saved text/VTT files on the owning machine. It downloads available captions; videos without captions return an error. No audio transcription is implied.

Connections and credentials

Assume the user is on a phone on the same network. Discover media-hub.publish, then send {"path":"ABSOLUTE_OUTPUT_PATH"} on the machine holding that file or folder. Return its ready hostname URL. For access outside the network, add "audience":"external"; the hub uploads to Dropbox /ai-workspace and checks public link access. Never publish externally by default.

Use media-hub.diagnostics to check the LAN hostname, output path, storage, and Dropbox authorization. A successful local check does not verify phone reachability. Report failures instead of inventing share links.

The website, files, and AI task API share port 3002. Task execution uses authenticated /v1/ routes on that same listener; opening a gallery does not grant task access. Credentials are retrieved locally from the native OS store.

For another local MCP client, launch node /absolute/path/to/agent-tools/src/mcp.mjs over stdio. For another machine, pair its hub first. The website URL alone does not grant an agent task access.

Available and planned

Local galleries, path publishing and transcript tasks are supported. Dropbox publishing requires native hub authorization. Image generation is disabled in this separate preview. Voice uses an existing external adapter; music is planned.
