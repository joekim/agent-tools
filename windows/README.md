# Windows desktop tools

- [Hotkeys](hotkeys/README.md): global keyboard shortcuts and notifications.
- [Screenshots](screenshot/README.md): capture all monitors to a PNG and the clipboard.

These Windows-only tools are tracked here alongside the cross-platform hub. Their existing installations under `~/projects/agent-tools/hotkeys` and `~/projects/agent-tools/screenshot` remain active. The saved hotkey commands still point to those installations; moving the source into this directory does not change startup shortcuts or the hub's configured `legacyToolsRoot`.
